# 달레 스터디 개발자 설문조사

[![All Contributors](https://img.shields.io/github/all-contributors/DaleStudy/survey?color=ee8449&style=flat-square)](#contributors)

개발자 커뮤니티 [달레 스터디](https://dalestudy.com)가 진행하는, 한국 개발자를 대상으로 한 설문조사입니다. 한국어 환경에 맞는 디자인 시스템 [달레 UI](https://www.daleui.com)로 만들었습니다.
