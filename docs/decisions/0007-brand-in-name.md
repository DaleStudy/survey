# 0007. 이름에 달레 스터디를 넣어 "달레 스터디 개발자 설문조사"로 한다

- 상태: 확정
- 날짜: 2026-11-01
- 대체: [0006](0006-rename-survey.md)

## 맥락

0003과 0006은 외부 채널이 공유하기 쉽도록 이름에서 운영 주체를 빼고 "한국 개발자 설문조사"로 정했다. 오픈을 앞두고 사이트에 dalestudy.com 의 그라데이션, 로고, 하단을 들여오면서 브랜드는 이미 화면 곳곳에 드러나게 됐다. 그런데 이름에 브랜드가 없으면 결과가 인용되어도 달레 스터디라는 이름이 쌓이지 않는다.

국내 선례인 프로그래머스는 "프로그래머스 개발자 설문조사", 해외는 Stack Overflow Developer Survey, JetBrains State of Developer Ecosystem 처럼 "운영 주체 + 개발자 설문조사" 형태를 쓴다.

## 결정

- 이름은 **"달레 스터디 개발자 설문조사"**이고, 앞에 연도를 붙인다. 예: 2026 달레 스터디 개발자 설문조사.
- 영문 이름은 **DaleStudy Developer Survey**로 한다.
- 조사 대상(개발자)은 이름에서 빼지 않는다. "달레 스터디 설문조사"만 쓰면 커뮤니티 회원 대상 내부 설문으로 읽힌다.
- 좁은 화면의 헤더는 로고 마크가 달레 스터디를 대신하므로 "개발자 설문조사"만 쓴다.

## 검토한 대안

- **"한국 개발자 설문조사" 유지:** 중립적이라 외부 채널이 공유하기 쉽다. 하지만 브랜드가 쌓이지 않고, 운영 주체는 이미 디자인으로 드러나 중립성의 이점이 줄었다.
- **"달레 스터디 설문조사":** 짧지만 조사 대상이 빠져 내부 설문처럼 보인다.

## 결과

- 외부 채널(GeekNews 등)이 커뮤니티 홍보로 여길 수 있다. 연락할 때 조사 대상이 한국 개발자 전체이고 결과를 모두 공개한다는 점을 앞세운다.
- 오픈 뒤에는 이 이름을 바꾸지 않는다.
