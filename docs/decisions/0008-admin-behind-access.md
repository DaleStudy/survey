# 0008. 운영자 화면은 Cloudflare Access 로 잠근 `/admin` 에 둔다

- 상태: 확정
- 날짜: 2026-11-07
- 논의: [#10](https://github.com/DaleStudy/survey/issues/10)

## 맥락

설문이 열리면 응답이 얼마나 쌓였는지 수시로 봐야 한다. 지금은 D1 을 직접 조회하거나 `bun run export` 로 CSV 를 받아야 한다.

이 사이트에는 로그인이 없고, 관리자 인증을 새로 만들지 않기로 했었다. 처리방침 8번에는 "원본 응답에는 운영자 1명만 접근할 수 있습니다"라고 공개했다. 원본 응답에는 나이, 지역, 회사, 연봉 구간처럼 함께 보면 응답자를 짐작할 수 있는 값과 자유 의견이 들어 있다.

## 결정

- 운영자 화면은 `/admin` 에 두고 읽기만 한다. 회차별 총 응답 수, 날짜별 응답 수, 원본 응답 테이블(50건씩)을 보여 준다. 응답을 고치거나 지우는 기능과 SQL 입력창은 두지 않는다. 직접 조회는 Cloudflare 대시보드의 D1 콘솔로, CSV 는 `bun run export` 로 한다.
- 로그인은 베타에서 쓰는 Cloudflare Access 의 GitHub 로그인을 재사용한다. 관리자 앱은 `/admin` 을 GitHub `DaleStudy/maintainer` 팀(운영진)에게 연다. 오픈 뒤 응답 추이를 운영진이 함께 봐야 해서 1명으로 묶지 않고, 처리방침 8번을 "운영진만 로그인해서 접근"으로 고친다. 접근 대상을 다시 바꾸면 처리방침도 함께 고친다.
- 데이터는 서버 함수가 아니라 `/admin/api` 서버 라우트가 준다. Access 는 잠근 경로로 가는 요청에만 `Cf-Access-Jwt-Assertion` 헤더를 붙이는데, 서버 함수는 `/_serverFn` 으로 요청하고 이 경로는 오픈하면 설문 제출을 위해 풀어야 한다.
- 서버는 요청마다 토큰의 RS256 서명, 발급자(팀 도메인), 관리자 앱의 AUD, 유효 기간을 확인하고, 하나라도 어긋나거나 확인할 수 없으면 거절한다. Access 설정이 빠지거나 잘못돼도 원본이 열리지 않게 하려는 것이다.
- 화면은 서버에서 그리지 않아(`ssr: false`) 페이지 HTML 에 응답이 들어가지 않는다. `/admin/api` 응답에는 `Cache-Control: no-store` 와 `X-Robots-Tag: noindex` 를 붙인다.
- 미리보기 주소의 `/admin` 도 같은 관리자 앱이 잠근다. 미리보기는 `survey-preview` 를 읽으므로 운영 응답이 드러나지 않고, 오픈 전에 화면을 미리보기에서 확인할 수 있다.

## 검토한 대안

- **`bun run export` 만 쓰기:** 추가 코드가 없지만, 오픈 뒤 추이를 볼 때마다 CSV 를 받아 열어야 한다.
- **`DaleStudy/feedback` 의 `/manage` 같은 GitHub OAuth:** 세션과 OAuth 앱을 이 화면 하나를 위해 들여오기에는 과하다.
- **서버 함수로 조회하기:** `/admin` 을 잠가도 서버 함수의 주소는 공개돼 있고, 관리자 앱의 토큰도 실리지 않는다.
- **`jose` 로 토큰 검증하기:** 검증하는 값이 몇 개 안 돼서, 의존성을 늘리지 않고 Workers 의 WebCrypto 로 확인한다.

## 결과

- 로컬 개발에서는 토큰이 없어 `/admin` 이 늘 거절된다. 화면은 미리보기에서 확인한다.
- 오픈할 때 베타 앱을 끄더라도 관리자 앱은 남긴다.
- 관리자 앱의 AUD 는 `src/lib/access.ts` 에 공개 값으로 둔다. 앱을 다시 만들면 이 값을 바꾼다.
