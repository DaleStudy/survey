# 0003. 설문 이름은 "한국 개발자 설문"으로 한다

- 상태: Superseded by [0006](0006-rename-survey.md)
- 날짜: 2026-10-31

## 맥락

[배포 채널 조사](../research/2026-10-distribution-channels.md)에서 가장 큰 위험은 응답이 달레 스터디 참가자(주니어·이직 준비생) 쪽으로 쏠리는 것이었다. 시니어·현업 개발자에게 닿으려면 GeekNews, OKKY, FE News 같은 외부 채널이 공유해 줘야 한다. 그런데 GeekNews는 "특정 서비스의 홍보 채널이 되지 않도록" 운영한다.

## 결정

- 이름은 **"한국 개발자 설문"**이고, 앞에 연도를 붙인다. 예: 2026 한국 개발자 설문.
- 결과 리포트는 "2026 한국 개발자 설문 결과"라고 부른다.
- 영문 이름은 **Korea Developer Survey**로 한다.
- 운영 주체는 부제("달레 스터디가 운영하는 연례 설문")와 도메인(`dalestudy.com` 하위)으로 밝힌다.

## 검토한 대안

- **달레 스터디 개발자 설문:** 운영 주체가 분명하다. 하지만 외부 개발자에게는 커뮤니티 내부 설문처럼 보이고, 다른 커뮤니티가 공유하기 부담스럽다.
- **State of Dev Korea 류:** 해외 설문과 비슷해 익숙하다. 하지만 State of Dev in South Korea(Dev Korea)와 State of FE·JS Korea(FE News)가 이미 있어 혼동된다.
- **별칭(K-개발자 리포트 등):** 기억에 남지만 매년 쓰기에는 가볍다. 필요하면 2회차 이후 반응을 보고 붙인다.

## 결과

- 매년 결과를 인용할 때 같은 형식으로 이어진다. 그래서 이름을 바꾸면 연도별 인용이 끊긴다.
- 화면의 헤더와 제목은 이 이름을 쓴다. "달레 스터디"는 부제, 푸터, 도메인에만 둔다.
