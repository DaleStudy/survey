# 문항 구조 비교 조사 (2026-10-31)

해외·국내 개발자 설문의 문항 구조를 비교해 1회차 문항 설계의 근거를 모았다. 표기: **[확인]** 원문에서 본 것, **[2차]** 기사·요약에서만 본 것, **[제안]** 판단.

## 결론

- **규모 [제안]:** 25~32문항, 응답 시간 중앙값 10~12분. 경품 없는 익명 설문이라 응답 동기가 공익성과 결과 공유뿐이다. 20~30분짜리 해외 설문처럼 길게 가면 안 된다.
- **근거:**
  - Stack Overflow 2025 는 62문항이었고 2024년 응답 시간 중앙값이 약 21분이었다. 길이가 "너무 길다"는 응답이 2024년 29.4%에서 2025년 42%로 늘었다 [확인].
  - SurveyMonkey 분석(약 10만 건, 2009~2010)에서는 7~8분을 넘으면 완료율이 5~20% 떨어졌고, 15번째 문항까지 이탈이 가장 가팔랐다 [확인].
  - 프로그래머스 2023 리포트에 나온 문항은 34개이고, 이 규모로 4,034명을 받았다 [확인].
- **배치 [제안]:** 인구통계는 앞에 최소한만 두고, 연봉·성별 같은 민감 문항은 뒤쪽에 선택 응답으로 둔다. State of Devs 2025 는 초반 10~20% 구간에서 약 5.5%가 이탈했다 [확인].

## 섹션 구성 초안 [제안]

| 섹션 | 문항 수 | 성격 |
|---|---|---|
| A. 나에 대해 (현재 상태, 경력, 직무, 연령대, 지역) | 5~6 | 고정 |
| B. 일하는 곳 (고용 형태, 회사 유형, 규모, 원청·하청 위치, 근무 형태, 근무 시간) | 6~7 | 고정 |
| C. 보상 (세전 연봉 구간, 지난 1년 변화) | 2 | 고정, 선택 응답 |
| D. 커리어 (만족도, 구직·이직, 코딩 테스트, 회사 선택 기준, 고민) | 5~6 | 고정 |
| E. 기술 (주력 언어, 배우고 싶은 언어) | 2~3 | 고정, 선택지는 해마다 갱신 |
| F. 올해의 주제: AI | 4~5 | 사용 빈도 1개만 고정, 나머지는 해마다 교체 |
| G. 마무리 (자유 의견, 선택적으로 성별) | 1~2 | 선택 |

## 매년 고정할 핵심 문항 후보 [제안]

다른 설문이 실제로 이렇게 쓰고 있다. 프로그래머스는 근무 형태·회사 선택 기준·정보 채널을 고정해 3년 시계열을 보여 줬고, Stack Overflow는 연봉에 전년 비교 차트를 붙였다 [확인].

| 문항 | 이유 |
|---|---|
| 현재 상태 (현업 / 구직 / 학생·준비생 / 이직 준비) | 모든 분석의 기준 |
| 경력 구간 | 교차 분석의 축 |
| 직무 (최대 2개) | 프로그래머스 방식과 비교 가능 |
| 고용 형태, 회사 유형 | 해외 설문이 놓치는 한국 맥락 |
| 회사 규모 | 해외 비교용 |
| 근무 형태 | 프로그래머스 2020~2022 시계열과 이어짐 |
| 세전 연봉 구간 | 연도별 변화가 가장 많이 읽히는 지표 |
| 직무 만족도 (5점) | SO·State of Devs와 같은 형식 |
| 지난 1년 구직·이직, 코딩 테스트 응시 | 국내 고유 관심사 |
| 회사 선택 기준 (최대 3개) | 프로그래머스 시계열과 이어짐 |
| 주력 언어 | 기술 문항 중 이것만 고정 |
| 업무 AI 도구 사용 빈도 | AI 주제 중 이것만 고정 |

문구, 선택지 구간, 선택지 순서는 바꾸지 않는다. 선택지는 "기타"를 쪼개는 방식으로만 늘린다.

## 민감 문항 처리

| 항목 | Stack Overflow | Devographics | 프로그래머스 2023 |
|---|---|---|---|
| 연봉 | 숫자 입력, 연간 총보상, 세전, 비워 둘 수 있음 | USD 세전 구간 | 원화 1천만 원 단위 구간, "선택 안 함" 있음. 세전·세후 정의는 확인 안 됨 |
| 나이 | 10년 구간 + 응답 안 함 | 10년 구간 | 5년 구간 + 선택 안 함 |
| 지역 | 국가 | 국가 | 근무지 시·군·구 |
| 회사 규모 | 전체 직원 수 9구간 | 본인 포함 인원 9구간 | 개발자 수 4구간 |
| 경력 | 5년 단위, 코딩·직업 경력 분리 | 5년 단위 | 1년 미만 ~ 15년 이상 7구간 |

**권장 [제안]** ([개인정보 조사](2026-10-privacy-law.md)와 함께 본다)
- **연봉:** 원화 1천만 원 단위 구간. 1억 이상은 1억~1억5천 / 1억5천~2억 / 2억 이상으로 굵게 묶는다. 정의를 "세전, 계약 연봉(성과급 제외)"으로 못 박고 문구에 예시를 넣는다. "응답하지 않음"을 둔다.
- **나이:** 5년 구간, 45세 이상은 하나로 묶는다.
- **지역:** 시·도까지만 받는다. 시·군·구는 다른 응답과 조합하면 개인이 드러날 수 있다.
- **성별:** 맨 뒤 선택 응답으로 두거나 1회차에서는 뺀다.

## 한계

- SO 2025 의 응답 시간 중앙값, 성별 문항이 있었는지 여부는 확인하지 못했다.
- JetBrains 가 연봉을 구간으로 받는지 정확한 금액으로 받는지는 2차 자료뿐이다.
- 프로그래머스 실제 설문지의 문항 수, 소요 시간, 연봉 정의는 확인하지 못했다. 1억대 구간 경계값은 차트 이미지를 읽은 것이라 불확실하다.
- 권장 규모, 섹션 구성, 고정 문항, 구간 설계는 모두 제안이다. 검증된 기준이 아니다.
